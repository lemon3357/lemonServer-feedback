# 幽柠之域 · Bug 与反馈收集

欢迎来到 **幽柠之域** Mindustry 服务器的官方反馈仓库！
这里用来收集游戏里的 Bug、异常，以及大家对服务器的建议与想法。

## 📮 如何反馈

点击上方 **Issues → New issue**，选择合适的模板填写：

- 🐛 **Bug 反馈** —— 游戏里遇到的报错、卡顿，或贴图 / 道具 / 指令等异常
- 💡 **建议 / 反馈** —— 新玩法、平衡性、体验优化等各类想法

> 提交前请先在 [已有 issue](../../issues?q=is%3Aissue) 里搜一下，避免重复反馈~

## ✅ 反馈须知

- 尽量写清 **发生时间**、**所在服务器 / 模式** 和 **复现步骤**，方便定位。
- 附上 **截图或录屏** 会极大加快处理速度（图片可直接拖进输入框）。
- 一个 issue 只描述一个问题，方便逐条跟进。
- 请文明交流，恶意刷屏会被关闭并锁定。

## 🏷️ 处理状态说明

我（运营）会通过 **标签（Label）** 实时更新每条反馈的处理进度：

| 标签 | 含义 |
|------|------|
| `待确认` | 已收到，尚未核实 |
| `已确认` | 问题确实存在，已列入处理 |
| `处理中` | 正在修复 / 开发 |
| `已修复` | 已在代码层面修复，等待上线 |
| `已上线` | 修复已部署到服务器，可以体验了 |
| `不予处理` | 暂不修复（会附上原因） |
| `重复` | 与已有反馈重复 |

处理完成后，我会在对应 issue 下 **留言说明修复情况** 并关闭。重大更新也会在置顶 issue 里统一公告。
